# 文字转语音网页 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个单文件 `index.html`,用浏览器内置语音把文字读出来,可调语速、可选发音人,并在桌面 Chrome/Edge 上支持录制导出。

**Architecture:** 单文件,内联 CSS 与一个 IIFE 包裹的 script。script 内按职责分五个模块:`chunker`(纯函数切块)、`voices`(发音人列表)、`speaker`(播放队列)、`recorder`(录制导出)、UI 绑定层。全部挂到一个 `window.tts` 调试对象上,便于在控制台手动验证。

**Tech Stack:** 原生 HTML/CSS/JS,Web Speech API(`speechSynthesis`)、`MediaRecorder` + `getDisplayMedia`。零依赖、零构建。

**测试策略:** 用户选择不做自动化测试。每个任务用以下两种方式验证:(a) `node` 一行命令做语法检查;(b) 在浏览器中手动操作或控制台输入,核对预期输出。

## Task 2: 分块器 chunker

**Files:**
- Modify: `index.html`(script 段)

**为什么需要:** Chrome 桌面版会静默截断过长的朗读内容(约 15 秒即断),所以必须先切成小块排队朗读。

- [ ] **Step 1: 写入 chunker 模块**

把 script 中的注释行替换为如下内容:

```js
  // ---- 常量 ----
  const MAX_CHARS = 5000;
  const MAX_CHUNK = 200;   // 单块上限,防止 Chrome 截断
  const MIN_CHUNK = 60;    // 短于此时不在句末切,避免停顿过碎
  const SENTENCE_END = '。！？!?；;…';

  // ---- chunker:把长文本切成适合朗读的小块 ----
  function chunk(text) {
    const out = [];
    let buf = '';
    for (const ch of String(text)) {
      if (ch === '\n') {
        if (buf.trim()) out.push(buf.trim());
        buf = '';
        continue;
      }
      buf += ch;
      const tooLong = buf.length >= MAX_CHUNK;
      const endsSentence = SENTENCE_END.includes(ch) && buf.length >= MIN_CHUNK;
      if (tooLong || endsSentence) {
        if (buf.trim()) out.push(buf.trim());
        buf = '';
      }
    }
    if (buf.trim()) out.push(buf.trim());
    return out;
  }
```

```js
  // ---- voices:系统发音人列表 ----
  const voices = {
    all: [],
    sort(list) {
      const rank = v => {
        const l = (v.lang || '').toLowerCase();
        if (l.startsWith('zh')) return 0;
        if (l.startsWith('en')) return 1;
        return 2;
      };
      return [...list].sort((a, b) =>
        rank(a) - rank(b) ||
        (a.lang || '').localeCompare(b.lang || '') ||
        (a.name || '').localeCompare(b.name || ''));
    },
    load() {
      this.all = this.sort(window.speechSynthesis.getVoices() || []);
      return this.all;
    },
    get(uri) {
      return this.all.find(v => v.voiceURI === uri) || null;
    }
  };
```

## Task 4: 播放队列

**Files:**
- Modify: `index.html`(script 段)

**关键点:** 用自增的 `generation` 令牌让「停止」后残留的 `onend` 回调失效——`speechSynthesis.cancel()` 在部分浏览器里仍会触发旧回调,不拦住就会继续朗读下一块。

- [ ] **Step 1: 写入 speaker 模块**

在 voices 模块之后插入:

```js
  // ---- speaker:分块朗读队列 ----
  const speaker = {
    queue: [],
    index: 0,
    state: 'idle',        // idle | playing | paused
    rate: 1,
    voiceURI: '',
    generation: 0,
    onStateChange: null,  // 由 UI 层赋值

    setState(s) {
      this.state = s;
      if (this.onStateChange) this.onStateChange(s);
    },

    start(text) {
      this.stop();
      const gen = ++this.generation;
      this.queue = chunk(text);
      this.index = 0;
      if (!this.queue.length) return;
      this.setState('playing');
      this.speakCurrent(gen);
    },

    speakCurrent(gen) {
      if (gen !== this.generation) return;
      const piece = this.queue[this.index];
      if (piece === undefined) { this.setState('idle'); return; }

      const u = new SpeechSynthesisUtterance(piece);
      u.rate = this.rate;
      const v = voices.get(this.voiceURI);
      if (v) { u.voice = v; u.lang = v.lang; }

      u.onend = () => {
        if (gen !== this.generation) return;   // 已被 stop() 取消
        this.index++;
        this.speakCurrent(gen);
      };
      u.onerror = (e) => {
        if (gen !== this.generation) return;
        if (e.error === 'interrupted' || e.error === 'canceled') return;
        console.warn('朗读出错:', e.error);
        this.stop();
      };

      window.speechSynthesis.speak(u);
    },

    pause() {
      if (this.state !== 'playing') return;
      window.speechSynthesis.pause();
      this.setState('paused');
    },

    resume() {
      if (this.state !== 'paused') return;
      window.speechSynthesis.resume();
      this.setState('playing');
    },

    stop() {
      this.generation++;                        // 令所有旧回调失效
      const s = window.speechSynthesis;
      // Chrome 在 paused 状态下 cancel 可能不生效,先 resume 再 cancel
      if (s.paused) s.resume();
      s.cancel();
      this.queue = [];
      this.index = 0;
      this.setState('idle');
    }
  };
```

## Task 6: 导出(录制)

**Files:**
- Modify: `index.html`(script 段)

**背景:** `speechSynthesis` 不暴露音频数据,无法直接合成文件。唯一可行的路径是 `getDisplayMedia` 捕获本标签页音频 + `MediaRecorder` 录制,因此导出耗时等于实际朗读时长,产物为 webm。

- [ ] **Step 1: 写入 recorder 模块**

在 speaker 模块之后插入:

```js
  // ---- recorder:录制标签页音频导出为 webm ----
  const recorder = {
    mr: null,
    stream: null,
    chunks: [],

    supported() {
      if (!navigator.mediaDevices || !navigator.mediaDevices.getDisplayMedia) return false;
      if (typeof MediaRecorder === 'undefined') return false;
      // Safari 的 getDisplayMedia 拿不到音轨,直接判不支持
      const ua = navigator.userAgent;
      const isSafari = /safari/i.test(ua) && !/chrome|chromium|edg|android/i.test(ua);
      if (isSafari) return false;
      return true;
    },

    pickMime() {
      const candidates = ['audio/webm;codecs=opus', 'audio/webm', 'audio/mp4'];
      return candidates.find(t => MediaRecorder.isTypeSupported(t)) || '';
    },

    async start() {
      // Chrome 要求同时请求 video 才能共享标签页音频
      this.stream = await navigator.mediaDevices.getDisplayMedia({
        video: true,
        audio: true
      });
      const audioTracks = this.stream.getAudioTracks();
      if (!audioTracks.length) {
        this.release();
        throw new Error('NO_AUDIO');
      }
      audioTracks[0].addEventListener('ended', () => this.abort());

      const audioOnly = new MediaStream(audioTracks);
      const mimeType = this.pickMime();
      this.mr = new MediaRecorder(audioOnly, mimeType ? { mimeType } : undefined);
      this.chunks = [];
      this.mr.ondataavailable = (e) => {
        if (e.data && e.data.size) this.chunks.push(e.data);
      };
      this.mr.onstop = () => this.save(mimeType);
      this.mr.start();
    },

    release() {
      if (this.stream) {
        this.stream.getTracks().forEach(t => t.stop());
        this.stream = null;
      }
    },

    // 录制完成 → 下载
    save(mimeType) {
      const type = mimeType || 'audio/webm';
      this.release();
      if (!this.chunks.length) return;
      const blob = new Blob(this.chunks, { type });
      this.chunks = [];
      const ext = type.includes('mp4') ? 'm4a' : 'webm';
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = 'tts-' + new Date().toISOString().slice(0, 19).replace(/[:T]/g, '-') + '.' + ext;
      a.click();
      setTimeout(() => URL.revokeObjectURL(url), 10000);
    },

    // 用户中途停止共享 → 直接收尾,不走 save
    abort() {
      this.chunks = [];
      if (this.mr && this.mr.state !== 'inactive') {
        this.mr.onstop = null;
        this.mr.stop();
      }
      this.release();
      recorder.onFinish && recorder.onFinish('aborted');
    },

    stop() {
      if (this.mr && this.mr.state !== 'inactive') this.mr.stop();
      else this.release();
    },

    active() {
      return !!(this.mr && this.mr.state === 'recording');
    },

    onFinish: null   // 由 UI 层赋值:(reason) => void
  };
```
