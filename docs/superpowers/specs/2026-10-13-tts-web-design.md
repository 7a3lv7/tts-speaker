# 文字转语音(TTS)网页 — 设计文档

日期:2026-10-13
状态:已确认

## 目标

一个纯前端的文字转语音工具,支持调整语速。约束:**跨平台 + 体积小**。

## 已确认的决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 语音引擎 | 浏览器内置 Web Speech API | 零依赖、零成本、离线可用、全平台 |
| 文件形态 | 单个 `index.html`,内联 CSS + JS | 双击即用,便于分发;体积 ~30KB |
| 功能范围 | 播放/暂停/停止 + 语速 + 声音选择 + 导出 | 用户选定 |
| 导出定位 | 能用的浏览器上提供即可 | 接受 Safari/移动端不可用 |
| 测试 | 用户手动验证 | 用户选定,不引入自动化测试 |

排除项:音调/音量调节(用户未选)、本地模型、云端 API。

## 界面

```
┌──────────────────────────────────────────┐
│  文字转语音                                │
│  ┌────────────────────────────────────┐  │
│  │  在这里输入或粘贴文字…               │  │
│  └────────────────────────────────────┘  │
│                            0 / 5000 字    │
│  语速  ○────────●────────○   1.0x        │
│  声音  [ 婷婷 (中文·系统)          ▾ ]    │
│  [▶ 播放] [⏸ 暂停] [⏹ 停止]      [⤓ 导出] │
└──────────────────────────────────────────┘
```

- 中文界面;手机端单列布局;深浅色跟随 `prefers-color-scheme`
- 快捷键:空格 = 播放/暂停,Esc = 停止
- 文本上限 5000 字,超出时截断并提示

## 内部结构

单文件内按职责分段,每段是一个独立模块:

| 模块 | 职责 | 接口 |
|---|---|---|
| `voices` | 加载系统发音人、按语言分组排序、记忆上次选择(localStorage) | `load()` → 列表;`select(id)` |
| `chunker` | 长文本按标点切块,每块 < 200 字 | `chunk(text)` → string[] |
| `speaker` | 播放队列:逐块朗读、暂停/继续/停止、实时改参数 | `play(text)` / `pause()` / `resume()` / `stop()` |
| `recorder` | 导出:录制标签页音频 → 下载 webm | `start()` / `stop()` |
| `ui` | 控件绑定与状态渲染 | — |

数据流:输入文本 → `chunker` → 队列 → 逐块 `speechSynthesis.speak()` → 播完触发下一块。

## 关键设计决策

### 1. 必须分块朗读

Chrome 桌面版会静默截断过长的朗读内容(约 15 秒)。因此长文本按标点(`。!?;,\n` 等)切分成 < 200 字的块,排队朗读。

副作用是收益:语速或声音变更在**下一块立即生效**,无需重头播放。

### 2. 语速范围 0.5x – 3.0x,步长 0.1

API 名义支持 0.1–10,但 3x 以上多数引擎会失效或音质崩坏,故上限卡在 3。当前值实时显示,点击数值复位到 1.0x。

### 3. 导出 = 录制,不是合成

`speechSynthesis` 不暴露音频数据,无法直接合成文件。导出流程:

1. 点击导出 → 说明弹窗(需选择"此标签页"并勾选**分享标签页音频**)
2. 确认后开始 `MediaRecorder` 录制
3. 自动从头朗读一遍
4. 朗读结束 → 停止录制 → 下载 `.webm`

已知限制(UI 中明示):
- 输出为 webm,非 mp3;时长等于实际播放时长
- 仅桌面 Chrome / Edge 能取得音轨;Safari 与移动端禁用按钮并说明原因
- 录制期间标签页不可静音

能力检测:检查 `navigator.mediaDevices.getDisplayMedia` 存在性;iOS/Safari 直接禁用按钮。

## 平台降级

| 情况 | 处理 |
|---|---|
| iOS Safari 不支持暂停/继续 | 隐藏暂停按钮,只保留停止 |
| 无中文语音包 | 提示安装路径(macOS:系统设置 → 辅助功能 → 朗读内容) |
| 不支持 `speechSynthesis` | 整页显示不支持提示 |
| 文本为空 | 禁用播放与导出按钮 |
| 录音权限被拒 / 用户未勾选分享音频 | 明确提示失败原因,不静默失败 |

## 语音列表加载

`getVoices()` 在 Chrome 上首次可能返回空数组,需监听 `voiceschanged` 事件重新加载。列表按语言分组,中文发音人排在最前。
